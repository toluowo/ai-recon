# Security Policy

## Supported Versions

Security fixes are applied to the actively maintained version of AI-RECON.

If you are using an older version, please upgrade to the latest available release before reporting an issue.

## Reporting a Vulnerability

If you discover a security vulnerability in AI-RECON, please do not report it through a public GitHub issue.

Instead, contact the project maintainer privately with:

* a description of the vulnerability
* the affected version or commit
* steps to reproduce the issue
* the potential security impact
* suggested remediation, if available

Please provide enough information to allow the issue to be reproduced and investigated.

## What to Expect

Security reports will be reviewed and assessed based on:

* reproducibility
* severity
* affected components
* potential impact

If the issue is confirmed, a fix will be developed and released as appropriate.

## Scope

AI-RECON interacts with external services and user-supplied targets. Security reports may include issues involving:

* command-line input handling
* credential handling
* dependency vulnerabilities
* unsafe data processing
* output handling
* collector integrations
* unexpected application behaviour

## Responsible Disclosure

Please avoid publicly disclosing a vulnerability until the project maintainer has had a reasonable opportunity to investigate and address the issue.

Thank you for helping improve the security of AI-RECON.
